# Edutantr Cybersecurity Internship Projects

## Overview
This repository contains hands-on cybersecurity internship projects completed during my internship at Edutantr. The projects focus on network reconnaissance, packet analysis, and practical security assessment techniques using industry-standard tools in a controlled lab environment.

---

## Projects Included

### 1. Network Scanning using Nmap
Performed network reconnaissance and service enumeration using Nmap.

#### Tasks Performed
- Port scanning
- Service version detection
- OS fingerprinting
- Basic network analysis

#### Commands Used
```bash
nmap <target-ip>
nmap -sV <target-ip>
sudo nmap -O <target-ip>
```

#### Tools Used
- Kali Linux
- Nmap
- VMware Workstation

---

### 2. Packet Analysis using Wireshark
Performed packet capture and traffic analysis using Wireshark.

#### Tasks Performed
- Captured network packets
- Analyzed protocols and traffic flow
- Observed communication behavior
- Investigated packet-level details

#### Tools Used
- Wireshark
- Kali Linux
